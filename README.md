# JobTracker

Aplikacija za pracenje prijava za posao. Dodam firme, unesem prijave i pratim u kojoj su fazi: prijavljeno, intervju, ponuda ili odbijeno.

## Sta aplikacija radi

- registracija i prijava korisnika (JWT token)
- dodavanje, izmena i brisanje firmi i prijava
- svaki korisnik vidi samo svoje podatke
- pretraga, filtriranje po statusu, sortiranje i stranice (paginacija)
- provera unetih podataka i na frontendu i na backendu
- pregled sa brojem prijava po statusu
- Swagger dokumentacija za API

## Tehnologije

- **Backend:** Java, Spring Boot, Spring Security, Spring Data JPA
- **Baza:** MySQL
- **Frontend:** Angular
- **Ostalo:** JWT, Swagger, JUnit i Mockito, Docker
